# House-style allowlist (AGENTS §5/§6).  Enforced by
# scripts/check-house-style.sh.
#
# One entry per line:  path:line:pattern — reason
#
#   path     repo-relative path of the file.
#   line     the line at the time the entry was written.  Advisory when
#            `pattern` is a code anchor; exact-match when it is a rule name.
#   pattern  EITHER a rule name (bean-accessor, ref-collection-param,
#            decision-number, glob-reexport, jargon-in-log) — then
#            path:line:pattern must all match — OR a substring of the
#            offending source line, matched by path + substring so the entry
#            survives line churn and fails closed when the code changes.
#   reason   why the site is legitimate.
#
# Blank lines and lines starting with '#' are ignored.  An entry that no
# longer matches any finding is reported as stale so the list can shrink.
#
# The list is intentionally short: a real violation is fixed, not allowlisted.
# A `get_*`/`set_*` pure field-mover, a whole-crate glob re-export, or a
# decision number in a comment is always a violation and does not belong here.

#     The method is the read-only API, so it is not a bean accessor. -------
