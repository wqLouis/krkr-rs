# Layering/unsafe allowlist (AGENTS §2/§5).  Enforced by
# krkr-gate layering.
#
# One entry per line:  path:line:pattern — reason
#
#   path     repo-relative path.  A shell glob is allowed (`*` matches `/`
#            too), so one reviewed location is one entry.
#   line     the line at the time the entry was written, or `*` for any line.
#            Advisory when `pattern` is a code anchor; exact-match when it is
#            a rule name.
#   pattern  EITHER a rule name (l1-vocabulary, l2-vocabulary, l3-platform,
#            unsafe-no-safety-note, unsafe-allow-outside-ffi,
#            missing-docs-lint) — then path, line and pattern must all match —
#            OR a substring of the offending source line, matched by path +
#            substring so the entry survives line churn and fails closed when
#            the code changes.
#   reason   why the site is legitimate or the debt is accepted.
#
# Blank lines and lines starting with '#' are ignored.  An entry that no longer
# matches any finding is reported as stale so the list can shrink.
#
# Two kinds of entry live here, and they are not the same thing:
#   * LEGITIMATE EXCEPTION — the rule does not apply at the site.
#   * KNOWN DEBT — the rule does apply and the site violates AGENTS, but the
#     fix is a tracked migration.  These are marked "debt:" so the guard does
#     not hide the violation behind a clean exit.
#
